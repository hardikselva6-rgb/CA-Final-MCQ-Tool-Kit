# CA Final MCQ Assessment Tool

A powerful web-based tool designed for CA Final students to practice MCQs, track performance, and analyze results with detailed insights.

## 🚀 Features

- ✅ Paste AI-generated MCQs (tab or pipe format)
- ✅ Timed test environment
- ✅ Question navigation panel
- ✅ Auto scoring system
- ✅ Detailed performance reports:
  - Score breakdown
  - Time per question
  - Weak areas
  - Speed vs accuracy
  - Question-wise analysis
- ✅ Review answers after test
- ✅ No login required (100% free)

## 📂 How to Use

1. Open the tool in browser
2. Paste MCQ questions in supported format
3. Set test name, your name, and time
4. Start test
5. View detailed analytics after submission
